# Basic Network Sniffer

## Project Description

This project is a basic network sniffer developed in Python using the Scapy library.

The program captures network packets and displays important information such as:

- Source IP address
- Destination IP address
- Network protocol
- Source and destination ports
- Packet size
- Packet payload

## Objectives

The main objectives of this project are:

- Understand how network packets work
- Learn how to capture network traffic
- Identify different network protocols
- Analyze basic packet information
- Practice Python programming and network security concepts

## Technologies Used

- Python 3
- Scapy
- Linux / Ubuntu
- VS Code

## Features

The network sniffer can analyze:

- TCP packets
- UDP packets
- ICMP packets
- IPv4 traffic
- Packet payloads
